AIForge — All-in-One AI Generator SaaS (Next.js)

## Short description (≤130 chars)

## Full description

**AIForge** is a complete AI creation workspace you can deploy and white-label.

### Features

- 7 generators: Writer, Image, Code, SEO, Social, Product Copy, Chat
- Dark marketing landing + responsive dashboard
- Auth with httpOnly sessions, email verification, password reset
- Credit system enforced on the server
- Demo AI mode (no API key) + live OpenAI mode
- Stripe subscriptions (Creator / Business) with signed webhooks
- Admin panel: users, plans, statistics, activity feed
- Dual storage: local JSON for VPS, Postgres for Vercel/serverless
- English documentation + marketplace license

### Technical stack

- Next.js 15, React 19, TypeScript, Tailwind CSS 4
- Stripe, Resend, OpenAI (optional)
- Neon/Postgres via `DATABASE_URL` for production demos

### Requirements

- Node.js 20.9+
- npm
- Postgres database when deploying to Vercel (Neon free tier works)
- Optional API keys: OpenAI, Stripe, Resend

### What’s included

- Full source code
- `docs/DOCUMENTATION.md` installation & customization guide
- `LICENSE.txt`
- `.env.example`

### Demo

Use the live demo URL on the product page. Register a free account — demo mode works without OpenAI keys.
